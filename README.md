# TFcalculator — калькулятор Transport Fever 2

Статический сайт (без сборки): расчёт количества транспорта, прибыли и окупаемости, сравнение видов транспорта, справочник по логике игры и лайфхаки.

Сайт лежит в папке `docs/`. Запуск: открыть `docs/index.html`. GitHub Pages: Settings → Pages → Deploy from branch → `main` / `/docs`.

Константы приблизительные (сообщество); калибруются во вкладке «Настройки».
